What is BitMessenger?
BitMessenger is an interactive simulation built for Computer Networks students. It demonstrates how text messages are encoded into binary code, protected with parity bits, transmitted across a simulated network channel, and decoded at the receiver side.

ASCII Mode vs Unicode:
• ASCII: 7 bits per character (0 to 127).
• Unicode: Padded binary code points for universal characters.
Parity Bit Mechanics:
• Format: [PARITY BIT][DATA BITS]
• Even Parity: Parity bit is set so total 1s = EVEN.
• Odd Parity: Parity bit is set so total 1s = ODD.

Note: Parity bit error detection is an educational check for single-bit flips and does not provide encryption or error correction.
